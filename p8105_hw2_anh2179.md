``` r
transit_df = 
  read_csv("NYC_Transit_Subway_Entrance_And_Exit_Data.csv",
  col_types = cols(Route8 = "c", Route9 = "c", Route10 = "c", Route11 = "c")) |>
  
  janitor::clean_names() |>
  select(
    line,station_name,station_latitude,station_longitude,starts_with("route"),
         entry,vending,entrance_type,ada) |>
  mutate(entry = recode_values(entry,"YES" ~ TRUE,"NO" ~ FALSE))
```

### This dataset describes entrances and exits at New York City subway stations. It includes each station’s line, name, and location (latitude and longitude), the routes it serves (route1–route11), and details about each entrance: whether it allows entry, whether it has a vending machine, its entrance type, and whether it is ADA compliant. We begin by importing the data, cleaning the variable names, and keeping only the columns needed for later parts of this problem. We convert entry from yes/no to a logical variable. During import, we also read route8–route11 as character so they match route1–route7. The resulting dataset has 1,868 rows and 19 columns. As it stands, these data are not tidy. Route number and route name should each be a single variable, but they are spread across 11 columns. To tidy the data, we would pivot the route columns from wide to long format.
