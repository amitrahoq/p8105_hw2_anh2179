### Paragraph about NYC Transit Dataset

This dataset describes entrances and exits at New York City subway
stations. It includes each station’s line, name, and location (latitude
and longitude), the routes it serves (route1–route11), and details about
each entrance: whether it allows entry, whether it has a vending
machine, its entrance type, and whether it is ADA compliant. I imported
the data, cleaned the variable names, and kept only the columns needed
for later parts of this problem. I then converted entry from yes/no to a
logical variable. I decided to also denote route8–route11 as characters
so they match route1–route7. The resulting dataset has 1,868 rows and 19
columns. The data is not tidy. Route number and route name should each
be a single variable, but they are spread across 11 columns.

### Paragraph about Tidying Baseline Demographic Data

To import the baseline data, I skipped the first row of the CSV because
it holds variable descriptions, not data, and treated `.` and `NA` as
missing values, which lets `age_at_onset` be read as numeric. I cleaned
the variable names with `janitor::clean_names()`. I “case matched”
(re-coded since case match doesn’t exist anymore) `sex` (1 = Male, 0 =
Female) and `apoe4` (1 = Carrier, 0 = Non-carrier) from numeric codes to
labeled categories, so they are not treated as numbers. To apply the
inclusion criteria, I kept participants who never developed MCI (missing
`age_at_onset`) and those whose onset came after their baseline age.
Participants whose onset was at or before baseline already had MCI when
they entered the study, so they are removed. The cleaned dataset has 479
rows and 6 columns: id, current_age, sex, education, apoe4,
age_at_onset. In total, 483 participants were recruited, and 479 remain
after applying the inclusion criteria. Of these, 93 developed MCI during
follow-up. The average baseline age is 65.0286013 years. Among women in
the study, the proportion who are APOE4 carriers is 0.3.

### Paragraph about Import Process and Features on Biomarkers

To import the biomarker data, I skipped the first row of the CSV because
it holds variable descriptions, not data. I cleaned the variable names
with `janitor::clean_names()` and renamed `study_id` to `id` so it
matches the baseline dataset. The resulting dataset has 487 rows and 6
columns. Each row is one participant, and the amyloid beta 42/40 ratio
is recorded at baseline and at years 2, 4, 6, and 8. The data is not
tidy, because time is spread across five columns, and is not specified
what unit of time it is. I tried using `pivot_longer()` to create a
`time` variable and an `amyloid_ratio` variable would give one row per
participant per visit, just like in problem 1, but I do not think that
would tidy time the way I wanted it to. Therefore, I renamed the time
columns to indicate how many years had passed from baseline amyloid beta
42/40 ratio.
